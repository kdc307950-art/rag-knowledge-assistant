# 律所落地说明：法律知识库问答

> 文档版本：`0.2`
> 适用应用版本：`0.1.0`
> 最近核对：`2026-08-22`

本说明把「企业知识库智能助手」落到**律师事务所**场景，用真实权威法律语料替换演示用员工手册，验证系统在「精确法条引用 + 严格拒答 + 跨文档检索」上的真实表现。

## 一、场景定位

**面向律所内部的法规问答**，典型用户画像：

- 律师在办案/合同审查时，快速定位「某条法律是怎么规定的」；
- 实习律师/助理查询法条原文，减少翻阅纸质法典的时间；
- 团队知识沉淀：把合同模板、办案指引、内部备忘录逐步纳入。

为什么从合同切入、逐步扩展到多领域：

- 合同业务是民商事诉讼/非诉团队**最高频**的业务线，法条精确引用需求最强（"第 X 条第 X 款"是日常用语）；
- 合同编配司法解释可验证**跨文档检索**；劳动合同法、公司法覆盖律所另两条高频业务线。

- 全部 `authoritative`，附带 control 证据包（发布机关、批准、施行日期、官方来源 URL）；

- 结构：章节标题顶格、法条独立成行，适配 `split_by_chapters` 分章。

## 三、系统能力 × 律所需求映射

| 律所痛点 | 系统能力 | 对应实现 |
| --- | --- | --- |
| 法条编号/术语精确召回 | 向量 + BM25 混合检索 + reranker | `rag/retriever.py` |
| 法律术语与法条原文表述不一致 | 检索前术语同义词扩展 | `rag/query_expansion.py` + `config/legal_terms.json` |
| 答错法条 = 执业风险 | RAG-First 严格拒答，无据可查即拒答 | 检索即裁决 |
| 回答要能回溯源条文 | 回答内来源编号，稳定溯源 | 来源追溯 |
| 不同团队看不同案卷 | 文档 ACL（部门/私有） | 检索前授权 |
| 合规审计 | 审计日志、离线备份、恢复演练 | `audit.log` + 备份脚本 |
| 数据权威性分级 | `authority_level`（authoritative/reference） | 文档治理 |

## 四、术语映射机制

法律专业术语与法条原文常不一致（如「缔约过失」在法条原文是"订立合同过程中…承担赔偿责任"），导致向量（bge-small-zh）与 BM25 都难以映射、rerank 低于阈值被误拒答。

方案：`config/legal_terms.json` 维护「术语 → 法条原文描述性表述」映射，检索与重排前对 query 做**追加式扩展**（保留原词 + 追加法条表述）。术语表为空时退化为无操作。

实测效果：22 用例 Recall@1 从 **94.4% 提升到 100%**（law_007「缔约过失责任」从误拒答变为正确召回，score 0.99）。

## 五、黄金集设计

评测用 `eval/retrieval_cases_law.jsonl`，schema v2，共 **44 条用例**：

- **民法典合同编 18 条**：精确法条引用 + 专有名词 + 跨条文引用；
- **合同编通则司法解释 4 条**；
- **公司法 4 条**、**劳动合同法 4 条**；
- **刑法 4 条**（故意伤害、盗窃、正当防卫、诈骗）、**刑诉法 4 条**（机关分工、证据、勘验检查、逮捕）；
- **跨文档 2 条**（`all_required`）：合同条款解释（民法典 466 条 + 司法解释第 1 条）、情势变更（民法典 533 条 + 司法解释第 32 条）；
- **拒答 4 条**：结婚年龄（婚姻家庭编）、继承顺序（继承编）、专利侵权（知识产权）、行政复议（行政法），验证知识库之外严格拒答。

可答案例单文档默认 `authoritative_only`（只检索对应 authoritative source）；跨文档用例 `all_required`；每个可答案例带人工核对的 `expected_evidence`（parent_id 锚点）。

### 未满分用例分析（真实发现）

1. **law_013「损失赔偿额」recall@1=0（@3 命中）**：rerank 把司法解释第六十五条「违约金以损失为基础」排到民法典第五百八十四条「损失赔偿额」之前——二者都以"损失"为核心、语义相近，属 rerank 排序偏差。
2. **cross_001/cross_002（跨文档）@1=0.5（@3 全命中）**：`all_required` 要求 top-k 同时覆盖两个 source，@1 单 chunk 天然无法满足，@3 即 100% 覆盖。
3. **refuse_005「行政复议」误答（拒答准确率 75%）**：query「对行政处罚不服如何申请行政复议？」的"对…不服…申请救济"句式与刑诉法第一百一十七条「对处理不服的，可以…申诉」高度相似，rerank 给 0.566（刚过 0.5 阈值）——知识库扩到刑事法律后，拒答边界出现弱相关公法 query 的混淆，属 rerank 阈值边界问题，也是行政法语料缺失的体现。

等价来源修正记录：law_003「违约金过高」初版仅标注民法典第五百八十五条，评测召回更精确的司法解释第六十五条（含"超过损失 30% 即认定过分高于"标准）被判未命中；改为 `any_equivalent`（民法典 + 司法解释等价）后命中，Recall@1 从 90.6% 提升到 93.75%。

## 七、已知边界与后续

1. **语料仍有限**：尚未纳入指导性案例、典型案例、地方性法规，以及律所私有语料（合同模板、办案 SOP）。
2. **单机架构**：当前单机单进程，适合百人规模律所内网部署，非多租户 SaaS。
3. **时效性**：法律有修订/废止，需配合文档治理的 `effective_to`/`supersedes` 机制做版本管理。
4. **术语表需持续维护**：当前 4 条术语，可按业务扩展（如公司法的「刺破公司面纱」「资本多数决」等）。
